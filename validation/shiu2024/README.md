# 검증: Shiu et al. 2024 원본 Brian2 모델 대 flydnet

같은 뉴런 ID·매개변수, 1초 x 30시행, 당 GRN 20개(21개 중 v783에 있는 것)·쓴맛 GRN 21개를 포아송 자극.
MN9(섭식 운동 뉴런) 발화율, 평균 ± 표준오차:

| 조건 | 원본 Brian2 | flydnet `timing="brian"` | p (Welch) |
|---|---|---|---|
| 무자극 | 0.0 | 0.0 | - |
| 단맛 25 Hz | 0.0 ± 0.0 | 0.0 ± 0.0 | 1.00 |
| 단맛 50 Hz | 12.6 ± 1.0 | 13.7 ± 0.9 | 0.41 |
| 단맛 100 Hz | 61.8 ± 0.9 | 62.7 ± 0.7 | 0.45 |
| 단맛 200 Hz | 88.8 ± 1.1 | 90.6 ± 0.9 | 0.22 |
| 쓴맛 100 Hz | 0.0 | 0.0 | - |
| 단맛 + 쓴맛 100 Hz | 2.2 ± 0.3 | 2.2 ± 0.3 | 1.00 |

- 모든 조건에서 차이가 시행 간 잡음 안 (p > 0.17).
- 단맛 100 Hz에서 반응한 뉴런 329개의 발화율: 원본과 상관 0.9985, 합 비율 0.998
  (예전 방식 `timing="legacy"`는 상관 0.93, 24% 과대).
- 같은 입력 스파이크를 넣으면 표적 뉴런의 스파이크 시각이 스텝 단위로 같다 (`tests/test_ganglion.py`,
  `tests/data/brian2_toy_trace.npz`).
- 시간: 원본 1시행 약 15초 (CPU, NumPy) / flydnet 30시행 약 26초 (RTX 5070) → 시행당 약 17배.

## 찾아서 고친 차이 (0.1.15까지의 방식)

1. 불응기 중에 도착한 시냅스 입력: 원본은 버리고, 예전 flydnet은 쌓아 두었다가 불응기 뒤 한꺼번에 반영 → 과대
2. 순서: 원본은 적분 → 발화 판정 → 입력 도착·자극 → 리셋 (입력은 다음 스텝부터)
3. 불응기: 원본은 21스텝 멈춤, 예전 flydnet은 22스텝
4. 적분: 원본은 정확한 선형 해(Brian `linear`), 예전 flydnet은 오일러 (차이 1%)

## 다시 돌리기

```bash
python compare.py                     # 저장된 결과로 표
python compare.py --run               # flydnet 쪽을 새로 계산 (GPU 약 3분)
# 원본 (다른 가상환경, 조건마다 약 8분):
python run_brian2.py --data <FlyWire 데이터 폴더> sugar_100 30
```
