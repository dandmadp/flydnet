# 검증: 스파이킹 층의 시간 역전파 기울기

`fd.gradcheck`: 연결 종류마다 배율을 ±5% 바꿔 실제 출력 변화(중심 차분)를 재고, 역전파 기울기와 방향(cos)·크기(비율)를
비교한다. 입력은 규칙 스파이크(무작위성 없음), 출력에 고정된 무작위 가중치를 곱한 합을 설명할 값으로.

| 조건 | 감쇠 없음 (0.1.15까지) | `surrogate_damp` 0.3 | 0.1 (0.1.16 기본) | 0.03 |
|---|---|---|---|---|
| 버섯체 dt 0.5, 100스텝 | cos 0.01 (크기 1.3배) | **0.87** (0.49배) | 0.67 (0.11배) | 0.37 |
| 버섯체 dt 0.1, 1,000스텝 | -0.38 (19억 배) | **0.75** (42배) | 0.49 (0.48배) | - |
| 예쁜꼬마선충 1,000스텝 | 0.15 (7억 배) | 0.16 (567배) | 0.11 (1.6배) | -0.61 |
| 합성 블록 (되먹임) 1,000스텝 | -0.40 (2억 배) | -0.43 (1,000배) | **0.87** (0.11배) | 0.65 |

같은 버섯체 1,000스텝에서 설명할 값(출력 가중치)을 바꾸면 0.1이 cos 0.97 (크기 1.3배)로 가장 좋았다.

- 감쇠 없이는 모든 조건에서 방향이 무작위이거나 반대이고, 긴 시뮬레이션에서 크기가 수억 배로 부푼다:
  대리 기울기가 되먹임 회로(KC ↔ APL 등)를 돌며 곱해짐
- 가장 좋은 값은 회로·길이·손실마다 다르다. 0.1은 평균적으로 방향이 낫고 크기가 실제와 비슷해(0.1~1.6배) 기본값으로
- 예쁜꼬마선충처럼 어떤 값으로도 맞지 않는 회로가 있다 → 학습 전에 `fd.gradcheck`, 맞지 않으면 `fd.ThreeFactor`
  (시간을 거슬러 가지 않음)나 짧은 시뮬레이션
- 구간 절단(`truncate`)은 시냅스 지연(18스텝)보다 충분히 길어야 한다: 버섯체에서 100스텝 cos 0.90~0.95,
  50스텝 0.06~0.31 (신호 경로가 끊김)
