# 검증: 스파이킹 층의 시간 역전파 기울기

`fd.gradcheck`: 연결 종류마다 배율을 ±5% 바꿔 실제 출력 변화(중심 차분)를 재고, 역전파 기울기와 방향(cos)·크기(비율)를
비교한다. **기준 신뢰도**(변화 폭 eps와 eps/2의 차분이 같은 방향인지)도 함께 잰다. 무작위성 없이 길게 돌린 스파이킹
회로는 출력이 연결 세기에 대해 울퉁불퉁해 기준이 성립하지 않을 수 있다 → 그때는 포아송 입력과 여러 seed의 평균
출력(매끄러운 기대값)으로 비교한다 (`gradcheck(..., seeds=16)`).

## 초파리

| 방향 일치 cos (크기 비율) | 감쇠 없음 (0.1.15) | 0.3 | 0.1 | auto (기본) |
|---|---|---|---|---|
| 버섯체 dt 0.5, 100스텝 (홉 25), 규칙 입력 | 0.01 (1.3배) | **0.87** (0.49배) | 0.67 | 0.29 |
| 버섯체 1,000스텝 (홉 55), 포아송·seed 8, 기준 0.94 | **-0.75** (16억 배) | - | **0.91** (1.4배) | 0.09 |
| 전체 뇌 200스텝 (홉 11), 규칙 입력, 기준 0.81 | **0.985** (10배) | 0.81 | 0.55 | 0.985 |
| 전체 뇌 1,000스텝, 규칙 입력, 기준 0.06 | 판단 불가 (기준 불안정) | | | |

막전위 잡음 1 mV (`noise=1.0`, 버섯체 1,000스텝): 감쇠 0.1과 함께 0.95, 0.3과 함께 **0.98** (1.3배).
잡음은 시뮬레이션 결과 자체를 바꾸므로 기본값이 아님.

## 다른 회로 (어떤 그래프든 회로로)

| | 감쇠 없음 | 0.3 | 0.1 |
|---|---|---|---|
| 합성 블록 (되먹임) 1,000스텝 | -0.40 (2억 배) | -0.43 | **0.87** |
| 예쁜꼬마선충 1,000스텝, 규칙 입력 | 기준 불안정 (eps에 따라 차분 부호가 바뀜) | | |
| 예쁜꼬마선충 1,000스텝, 포아송·seed 32, 기준 0.98 | 0.28 (30억 배) | 0.48 | 0.46 (3.4배) |

## 결론

- 감쇠 없이는 긴 시뮬레이션에서 방향이 무작위이거나 반대이고 크기가 수억 배로 부푼다 (대리 기울기가 되먹임 회로를
  돌며 곱해짐). 짧은 시뮬레이션에서는 감쇠가 오히려 해롭다 (전체 뇌 200스텝).
- 가장 잘 맞는 감쇠는 **홉 수**(시뮬레이션 스텝 / 시냅스 지연 스텝 = 신호가 시냅스를 건널 수 있는 횟수)로 설명된다:
  홉 11 → 1, 25 → 0.3, 55 → 0.1. 기본값 `"auto"` = min(1, (11 / 홉 수)^1.5)는 이 표에 맞춘 **경험 규칙**이다.
  다른 회로·손실에서는 `fd.gradcheck`로 확인하고 `fd.tune_surrogate`로 조정할 것.
- 예쁜꼬마선충은 깨끗한 기준으로도 cos 0.5 정도 - 대리 기울기가 부분적으로만 맞는 회로가 있다.
  `fd.ThreeFactor`도 같은 대리 기울기를 쓰므로 이 부정확함을 고치지는 못한다 (메모리·긴 시간 문제만 해결).
- 구간 절단(`truncate`)은 시냅스 지연(18스텝)보다 충분히 길어야 한다: 버섯체에서 100스텝 cos 0.90~0.95, 50스텝 0.06~0.31.

재현: `check_damping.py` (버섯체 2가지·예쁜꼬마선충·합성 블록, 약 15분).
